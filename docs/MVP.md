# MasterObrix AI — MVP v0.1

## Objetivo
Crear una primera aplicación mobile-first que permita a un profesional de construcción registrar proyectos y clientes y preparar presupuestos sencillos.

## Prioridad 1
1. Dashboard
2. Clientes
3. Proyectos
4. Presupuestos
5. Calculadora de materiales

## Prioridad 2
6. Gastos y ganancias
7. Cotizaciones exportables
8. Asistente IA

## Principios de producto
- Menos pasos que una hoja de cálculo.
- Lenguaje sencillo para contratistas.
- Diseño mobile-first.
- Español primero; arquitectura preparada para inglés.
- Los cálculos muestran unidades, cantidades y supuestos.
- No presentar cálculos como asesoría de ingeniería; deben verificarse antes de usarse en obra.

## Primer flujo
Dashboard → Nuevo proyecto → Datos del proyecto → Agregar cliente → Crear presupuesto → Agregar partidas → Total.

## Fuera del MVP inicial
- Nómina.
- Contabilidad fiscal.
- Integraciones bancarias.
- Marketplace.
- Automatización avanzada con IA.
